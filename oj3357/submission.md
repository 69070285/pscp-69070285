```text

The first line contains an integer n. (The number of giraffes)
The next n lines contain the heights of the giraffes.

Output:
Print one integer, which is the number of giraffes that are taller than both neighbors.

Constraints:
I can use 0 for the left side of the first giraffe and the right side of the last giraffe, so I can use the same comparison for every giraffe.
```
